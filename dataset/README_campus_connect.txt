CAMPUS CONNECT — ДЕМО-ДАТАСЕТ
================================

Файлы:
1. campus_connect_dataset_full.xlsx — удобная версия для просмотра и редактирования.
2. campus_connect_dataset_full.json — версия, которую удобно подключать к Python / FastAPI.
3. README.txt — этот файл.

ВАЖНО:
Все данные синтетические и созданы для демонстрации прототипа Campus Connect.
Это не официальная база данных УрФУ.

СОСТАВ ДАТАСЕТА
----------------
Users — 5 пользователей.
Projects — 20 проектов.
Events — 15 мероприятий.
Communities — 10 сообществ.

Applications — заявки пользователей в проекты.
EventRegistrations — регистрации пользователей на мероприятия.
CommunityMemberships — членство пользователей в сообществах.
Favorites — сохранённые пользователем проекты, события и сообщества.
Tags — словарь используемых интересов, навыков и категорий.

КАК СВЯЗАНЫ ТАБЛИЦЫ
--------------------
Во всех основных таблицах есть поле id.

Applications:
- user_id -> Users.id
- project_id -> Projects.id

EventRegistrations:
- user_id -> Users.id
- event_id -> Events.id

CommunityMemberships:
- user_id -> Users.id
- community_id -> Communities.id

Favorites:
- user_id -> Users.id
- object_type определяет тип объекта: project / event / community
- object_id содержит id объекта соответствующего типа

КАК СДЕЛАТЬ БЛОК «ДЛЯ ТЕБЯ»
----------------------------
У пользователя есть поле interests.
У проектов, мероприятий и сообществ тоже есть interests.

Простейшая рекомендация:
1. Разделить interests по символу ;
2. Посчитать количество совпавших тегов.
3. Чем больше совпадений — тем выше объект в выдаче.

Пример:
Артём:
IT; Программирование; Стартапы; Баскетбол

Проект «AI-помощник первокурсника»:
AI; IT; Программирование

Совпали IT и Программирование -> проект подходит Артёму.

ЧТО МОЖНО ПОКАЗАТЬ В ПРОТОТИПЕ
-------------------------------
- «Для тебя» — рекомендации по interests.
- «Мои проекты» — Applications со статусом «Принята».
- «Мои заявки» — все Applications пользователя.
- «Мои события» — EventRegistrations.
- «Мои сообщества» — CommunityMemberships.
- «Избранное» — Favorites.
- Кнопки «Подать заявку», «Записаться», «Вступить», «Сохранить».

ПОЛЕ image_slug
---------------
image_slug — короткое имя картинки, например campus-navigator.
Позже его можно связать с локальным файлом изображения или URL.

ДЛЯ БЭКЕНДА
-----------
Для демонстрации можно:
- читать JSON напрямую;
- либо загрузить эти таблицы в SQLite;
- либо создать seed-скрипт на Python, который один раз заполнит app.db.

Для хакатонного MVP этого датасета достаточно.
