URFU KNOWLEDGE BASE — CAMPUS CONNECT
====================================

Назначение
----------
Этот датасет — демонстрационная база знаний об УрФУ для Campus Connect.
Его можно использовать для:
- поиска по сайту;
- FAQ;
- чат-бота;
- RAG / AI-ассистента;
- блока быстрых ответов.

Дата проверки источников: 2026-09-04
Количество смысловых записей: 40

ВАЖНО
-----
1. Источники — официальные сайты УрФУ.
2. Текст в поле content — краткая пересказанная выжимка, а не копия страницы.
3. Поле source_url хранит официальный источник.
4. dynamic=true означает, что информация может меняться: сроки, контакты,
   суммы, правила, режимы работы, состав организаций и т.п.
5. Перед реальным запуском динамические записи желательно обновлять автоматически
   или периодически перепроверять.

ПОЛЯ
----
id          — уникальный номер.
category    — тематическая категория.
title       — короткое название факта/документа.
content     — содержимое для поиска и ответа пользователю.
keywords    — ключевые слова через ;
questions   — примеры вопросов пользователя через ;
source_name — название официального источника.
source_url  — ссылка на официальный источник.
dynamic     — может ли информация быстро устареть.

ПРИМЕР ИСПОЛЬЗОВАНИЯ
---------------------
Пользователь спрашивает:
"Есть ли спортзал в новом кампусе?"

Поиск ищет совпадения по:
questions + keywords + content

Находит запись:
"Спорт в Новокольцовском кампусе"

И возвращает content + ссылку source_url.

РЕКОМЕНДАЦИЯ ДЛЯ ХАКАТОНА
-------------------------
Для MVP можно просто загрузить urfu_knowledge_base.json в Python
и искать записи по совпадению слов.

Позже можно:
- загрузить записи в SQLite;
- сделать полнотекстовый поиск;
- добавить embeddings и векторный поиск;
- подключить автоматическое обновление официальных источников.
