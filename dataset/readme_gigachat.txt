ЧТО ЭТО
-------
Это база знаний для RAG (Retrieval-Augmented Generation), а не файл для
дообучения весов GigaChat.

Схема работы:
1. Пользователь задает вопрос.
2. Бэкенд получает embedding вопроса.
3. По embedding ищутся наиболее близкие блоки из urfu_rag_chunks.jsonl.
4. Несколько лучших блоков передаются GigaChat как контекст.
5. GigaChat формирует ответ только по найденному контексту.
6. Если данных недостаточно, ассистент сообщает об этом и не выдумывает факт.

ФАЙЛЫ
-----
urfu_rag_knowledge_base.json
  Полная база: meta + sources + chunks.

urfu_rag_chunks.jsonl
  Один смысловой блок на строку. Удобно для embeddings и индексации.

РЕКОМЕНДУЕМЫЙ SYSTEM PROMPT
---------------------------
Ты — цифровой помощник студента УрФУ.
Отвечай только на основании переданного контекста из базы знаний УрФУ.
Не используй собственные знания для добавления фактов, которых нет в контексте.
Если контекста недостаточно, ответь:
«В моей базе знаний УрФУ пока нет достаточной информации по этому вопросу».
Если блок помечен dynamic=frequent, предупреди, что информация может измениться,
и при необходимости укажи официальный source_url.
Не придумывай кабинеты, телефоны, сроки, суммы, правила или названия подразделений.

ОБНОВЛЕНИЕ
----------
dynamic=frequent: перепроверять чаще всего (контакты, суммы, сроки, правила,
режимы работы, поселение).
dynamic=yearly: перепроверять минимум перед учебным годом.
dynamic=static: периодическая проверка при изменениях структуры/правил.
